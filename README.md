# Say What Actually Broke

make.fun bounty entry: one line of software error copy that names the real
failure, tells you what to do next, and lands the joke in a single read.

## Entry

`main.ts` writes one line to `/output/entry.txt` (no trailing newline):

> Your disk is full. There is no room for this error message, let alone your data. Delete something - starting with those cat videos.
